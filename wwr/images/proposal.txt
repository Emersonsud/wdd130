1. What is the title of your program?
Word Frequency Counter

2. What real-world problem will your program address or help to solve?
When analyzing large text files (such as articles, essays, or books), it is difficult to quickly identify key topics or word repetition. This program automates text analysis by reading a file, cleaning the text, and providing statistics on word frequency and the most commonly used words.

3. What will you learn from developing this program?
I will learn how to read and process text files in Python, manipulate strings (converting case and removing punctuation), use dictionary data structures to keep track of frequencies, sort complex data structures, and write automated unit tests using pytest.

4. What Python modules will your program use?
os, string, and pytest.

5. List the names of functions you will need?
- read_file(filename)
- clean_text(text)
- count_words(cleaned_text)
- get_top_words(word_counts, top_n)
- main()

6. List the names of the test functions you will write.
- test_clean_text()
- test_count_words()
- test_get_top_words()
